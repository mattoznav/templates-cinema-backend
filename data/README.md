# Demo data

Each CSV file is a database table. `id` is the primary key, `<table>_id` columns are foreign keys, and list fields (directors, cast, countries, languages) are separated by `|`.

After editing, reload with `python manage.py load_data`.

## Sources

- `movies.csv`, `genres.csv`, `movie_genres.csv`: built by `tools/build_catalog.py`.
  - Facts from [Wikidata](https://www.wikidata.org), under [CC0](https://creativecommons.org/publicdomain/zero/1.0/).
  - The `synopsis` column is the lead paragraph of the Wikipedia article in `source_url`, under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). Credit the article wherever the synopsis is shown.
- `seats.csv`, `showtimes.csv`: generated by `tools/build_schedule.py`.
- `venue.csv`, `halls.csv`, `seat_types.csv`, `ticket_types.csv`: fictional, written by hand.
